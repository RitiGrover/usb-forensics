/ What this is not
  • Not a forensic image. It reads files the OS shows. No raw sectors, no unallocated space, no deleted files.
  • No write blocking. Use a hardware or validated write blocker before examining real evidence.
  • Timestamps are not proof. Browsers expose only the last-modified time, and it can be changed.
  • A hash is not authorship. Matching hashes mean matching bytes. A changed hash means different bytes, not wrongdoing.
  • Not a chain of custody. A CSV on its own is not an evidence record.
